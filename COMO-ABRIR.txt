MEU SITE 3D - COPIA COMPLETA PARA USAR NO SEU COMPUTADOR

1. De dois cliques em INICIAR-SITE.bat.
2. O navegador abre automaticamente quando o site estiver pronto.
3. Deixe a janela do servidor aberta enquanto usa o site.
4. Para parar, pressione Ctrl+C na janela do servidor.

O endereco normalmente sera http://127.0.0.1:3077/.
Se essa porta estiver ocupada, o inicializador escolhe outra ate 3097.
O endereco escolhido aparece na janela e em runtime\ULTIMO-ENDERECO.txt.
Se o site desta pasta ja estiver rodando, o BAT apenas abre esse servidor.

Nao precisa instalar Node, executar npm nem recompilar para abrir esta copia.
O Node para Windows, as dependencias, o build, o codigo-fonte e os assets 3D
estao incluidos. Pode mover a pasta completa para outro local neste computador;
nao mova apenas o BAT. O pacote foi testado neste Windows x64.
